Authentication
Getting Started with the API
The Acme API uses API keys for authentication. Include your key in the Authorization header of every request.
Example request
curl https://api.acme.com/v1/users \
-H "Authorization: Bearer YOUR_KEY" \
-H "Content-Type: application/json"
$
NOTE Keep your API key private. Do not include it in client-side code or public repositories.
